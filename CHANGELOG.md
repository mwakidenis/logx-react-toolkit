# Changelog

All notable changes to @mwakidenis/logx-react will be documented in this file.

## [0.1.0] - 2026-11-05

### Added

- Initial release of @mwakidenis/logx-react.
- Hooks: useToggle, useBoolean, useCounter, usePrevious, useLatest, useMounted, useArray, useObject, useDebouncedValue, useDebouncedCallback, useThrottle, useLocalStorage, useSessionStorage, useMediaQuery, useWindowSize, useClickOutside, useEventListener, useClipboard, useOnlineStatus, useTimeout, useInterval, useAsync.
- Components: CopyButton, DebouncedInput, PasswordInput, Responsive, ErrorBoundary.
- Providers: LogxProvider.
- Utilities: array, object, string, number, validation, date, browser.
- LOGX integration layer using @mwakidenis/logx at runtime.
- Vitest + React Testing Library test suite (75 tests).
- ESM, CommonJS, and TypeScript declaration builds via tsup.
- GitHub Actions CI workflow.
- Documentation and examples.
