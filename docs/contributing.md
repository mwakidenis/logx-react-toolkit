# Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) at the repository root. This page mirrors it for convenience.

## Development

```bash
npm install
npm run typecheck
npm run lint
npm test
npm run build
```

## Submitting changes

1. Fork the repository.
2. Create a feature branch.
3. Add or update tests.
4. Ensure typecheck, lint, and tests pass.
5. Open a pull request.
