# Roadmap

### 0.1.0 (current)

- Core hooks: state, performance, storage, browser, async.
- Components: CopyButton, DebouncedInput, PasswordInput, Responsive, ErrorBoundary.
- Utilities: array, object, string, number, validation, date, browser.
- LOGX integration layer.
- Tests (Vitest + React Testing Library).
- Documentation and examples.

### 0.2.0

- Additional hooks (e.g. useListState, useForm).
- Additional components.
- Improved documentation examples.

### 1.0.0

- Stable public API.
- Semantic versioning guarantees.
- Production-ready support for React 18 and 19.
