# Installation

```bash
npm install @mwakidenis/logx-react @mwakidenis/logx
```

`@mwakidenis/logx` is both a runtime dependency and must be installed explicitly alongside this package.

Peer requirements:

- React: `^18.2.0 || ^19.0.0`
- ReactDOM: `^18.2.0 || ^19.0.0`

```bash
npm install react react-dom
```

### Package manager

- npm: `npm install @mwakidenis/logx-react @mwakidenis/logx`
- yarn: `yarn add @mwakidenis/logx-react @mwakidenis/logx`
- pnpm: `pnpm add @mwakidenis/logx-react @mwakidenis/logx`

### Node version

Node `>=20` is required.
