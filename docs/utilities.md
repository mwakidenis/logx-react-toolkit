# Utilities

Utility modules are exported from `@mwakidenis/logx-react/utilities` and individual subpaths.

### array

Wrappers around @mwakidenis/logx array functions: `chunk`, `compact`, `difference`, `drop`, `flatten`, `flattenDeep`, `intersection`, `last`, `partition`, `sample`, `shuffle`, `take`, `union`, `unique`, plus `first` and `distinct`.

### object

Wrappers around @mwakidenis/logx object functions: `clone`, `deepClone`, `entries`, `get`, `has`, `keys`, `mapKeys`, `mapValues`, `merge`, `omit`, `pick`, `set`, `values`, plus `safeGet`.

### string

Wrappers around @mwakidenis/logx string functions: `camelCase`, `capitalize`, `escapeHtml`, `kebabCase`, `pascalCase`, `snakeCase`, `trim`, `truncate`, plus `htmlEscape`.

### number

Wrappers around @mwakidenis/logx number functions: `clamp`, `inRange`, `round`, `percentage`, `randomInt`.

### validation

Wrappers around @mwakidenis/logx validation functions: `isArray`, `isBoolean`, `isEmail`, `isEmpty`, `isFunction`, `isNil`, `isNull`, `isNumber`, `isObject`, `isString`, `isURL`, plus `required`.

### date

Wrappers around @mwakidenis/logx date functions: `addDays`, `isValidDate`.

### browser

Re-exports @mwakidenis/logx browser helpers: `isBrowser`, `isNode`, `hasLocalStorage`, `hasSessionStorage`.
