# Security

## Reporting a vulnerability

Please report security vulnerabilities to the project maintainer via GitHub
issue or email. Do not disclose security vulnerabilities in public issues or
pull requests until they have been addressed.

## Supported versions

Only the latest release of @mwakidenis/logx-react receives security updates.

## Disclosure policy

The maintainer will acknowledge receipt of a vulnerability report, investigate
it, and coordinate a fix and release timeline with the reporter.
